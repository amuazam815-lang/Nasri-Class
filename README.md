# Nasri Class

یہ GitHub/BWO Builder کے لیے بچوں کی تعلیمی ایپ ہے۔

## خصوصیات

- خوبصورت 3D-style بچوں والا UI
- A سے Z تک حروف
- ہر English حرف کے لیے آواز
- اردو حروف اور آواز
- Numbers 1-10
- English Poems
- اردو نظمیں
- Quran سیکشن
- Drawing / ڈرائنگ
- مختلف رنگ
- قلم کا سائز
- Drawing صاف کرنے کا بٹن
- Drawing محفوظ کرنے کا بٹن
- Back اور Home navigation
- 192×192 اور 512×512 icons
- بچے کی تصویر
- بنیادی Offline استعمال

## BWO Builder

index.html کو Start Page رکھیں۔

پورا assets فولڈر بھی ساتھ شامل کریں۔

## آواز

ایپ Android/WebView Text-to-Speech استعمال کرتی ہے۔

BWO Builder میں Text-to-Speech سپورٹ فعال ہونا ضروری ہے۔

Recorded MP3 آوازوں کے لیے اپنی قانونی/licensed audio files شامل کریں۔
